# ابدأ من هنا — CampusPass IQ v5.0.0

هذا إصدار جذري يركز على سهولة الاستخدام، صلاحية المالك، منع اختلاط حالات المحادثة، تعليمات التفعيل، البريد، التقييمات، الإعلانات، التقارير ومنشئ القوائم.

## قبل النشر

1. خذ Backup من PostgreSQL.
2. احتفظ بنفس `DATABASE_URL` و`ENCRYPTION_KEY`.
3. تأكد أن `ADMIN_IDS` يحتوي رقم Telegram الرقمي للمالك.
4. ارفع محتويات الحزمة إلى جذر GitHub.
5. نفّذ اختبار Staging قبل فتح البوت للعامة.

## أهم مسارات v5

### الطالب

```text
/start
→ اختيار المنصة والعرض
→ قراءة طريقة التفعيل
→ الدفع
→ استلام البيانات
→ طلب الرمز عند الحاجة
→ اكتمال الطلب
→ تقييم المنصة من 1 إلى 5 نجوم
```

### المنصة

```text
لوحة المنصة
→ الأقسام والخدمات والعروض
→ سعر العرض
→ طريقة التفعيل
→ تعليمات نص/صور/فيديو/ملف/رابط
→ المخزون أو البريد
→ الطلبات والتقارير والسحب
```

### المالك

```text
/admin
→ المنصات والصلاحيات
→ منشئ القوائم
→ الأسعار والميزات
→ الإعلانات المؤقتة والمثبتة
→ تقارير Standard / Plus / Pro
→ بلاغات مشاكل البوت
→ صحة النظام
```

## ملفات v5 المهمة

- `V5_RELEASE_NOTES_AR.md`: الميزات المضافة.
- `V5_UPGRADE_GUIDE_AR.md`: الترقية والرجوع الآمن.
- `V5_ADMIN_GUIDE_AR.md`: تشغيل المالك والمنصة.
- `V5_QA_REPORT_AR.md`: نتائج الفحص.
- `V5_LIMITATIONS_AR.md`: ما يحتاج اختبارًا حيًا.
- `V5_ACCEPTANCE_CHECKLIST_AR.md`: خطوات الاختبار بعد النشر.
- `examples/v5_reports/`: سبعة أمثلة HTML A4 ببيانات وهمية.

## أوامر الإنقاذ

```text
/menu   إظهار القائمة
/cancel إلغاء أي عملية معلقة
/admin  لوحة المالك
```

لا ترسل Bot Token أو DATABASE_URL أو كلمات مرور البريد في المحادثات.
