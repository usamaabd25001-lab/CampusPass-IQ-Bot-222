# البدء بإصدار V11.4 — Owner Commerce

هذا الإصدار مبني مباشرة فوق V11.3 ويضيف مركز التجارة والسيادة للمالك والمنصات.

## ما ينفذ
- فوترة B2B أسبوعية أو شهرية وتعليق تلقائي للمنصة المتأخرة.
- بريد إدارة مركزي موحد.
- إعلانات عامة ومثبتة وموجهة ومرتبطة بعروض.
- أكواد خصم موجهة للشرائح.
- باقات هجينة مع طلب فرعي لكل منصة وتوزيع مالي متوازن.
- حجز مخزون فعلي لكل مكوّن في الباقة الهجينة قبل الدفع.
- نظام مهام مقابل الرصيد مع تحقق Telegram الحقيقي.

## Render
- `render.yaml`: Staging مبسط بخدمة واحدة.
- `render.production.yaml`: Web + Worker منفصلان مع PostgreSQL وRedis إلزاميين.

## قبل النشر
1. ارفع المشروع إلى GitHub.
2. أنشئ PostgreSQL وRedis دائمين.
3. ضع متغيرات البيئة السرية في Render فقط.
4. طبق `alembic upgrade head`، والرأس الحالي `1140_owner_commerce`.
5. شغّل `python scripts/validate_v11_4_owner_commerce.py`.
6. اختبر Staging قبل تحويل الخدمة إلى Production.
