# CampusPass IQ V11.7.1 — All Features Ready

هذا الإصدار يفعّل جميع الميزات الاختيارية المطلوبة مع فصل واضح بين:

- **Enabled:** الميزة مطلوبة ومسموح بها في النظام.
- **Configured/Ready:** رُبطت بيانات المزود الخارجي وأصبح المسار التشغيلي متاحاً.

بهذا لا يتوقف Render بسبب مفتاح Gemini أو S3 أو بوابة دفع غير مضافة بعد.

## الحالة بعد التثبيت

- Gemini: مفعّل، ينتظر `GEMINI_API_KEY`.
- Mastercard: مفعّل، ينتظر عقد وبيانات بوابة الدفع.
- سحب المنصات: مفعّل، يفتح بعد جاهزية بوابة الدفع ونموذج marketplace.
- Backup: مفعّل، ينتظر S3.
- Image moderation: الفحص المحلي مفعّل فوراً؛ Google Vision اختياري.
- External evidence storage: مفعّل، ينتظر S3.

## النشر

استخدم `render.production.yaml`. القيم الأساسية القديمة تكفي لإقلاع البوت. أضف متغيرات التكاملات من ملف:

`ALL_FEATURES_VARIABLES_AR.md`

بعد إضافة أي مفاتيح، أعد نشر Web وWorker بنفس الإصدار.
