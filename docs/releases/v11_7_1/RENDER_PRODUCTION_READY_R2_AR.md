# Render Production Ready R2

هذا الإصلاح جراحي ومبني مباشرة على نسخة V11.7.1 All Features/Hotfix الأخيرة.

## سبب فشل البناء السابق

كان Dockerfile يشغّل سلسلة فاحصات تاريخية. الفاحص `verify_v10_railway_turbo.py` في النسخة المرفوعة على GitHub كان يفرض رقم V10.7 حرفياً، لذلك يرفض الإصدار الحالي V11.7.1 رغم أن الكود أحدث.

## التغييرات

- استبدال سلسلة فاحصات الإصدارات القديمة بفاحص إنتاج واحد واعٍ بالإصدار الحالي.
- الفاحص الجديد يتحقق من: Syntax، استيراد Entry Points، بناء Router، جميع FSM states، Registry الخاص بالـmigrations، قوالب التقارير، وملف Blueprint.
- إبقاء جميع الفاحصات القديمة داخل المشروع للتدقيق اليدوي؛ لم تُحذف.
- إطفاء بوابة Mastercard الآلية وسحب المزودين كما طلب المالك، مع بقاء الدفع اليدوي ورفع الوصلات.
- جعل النشر التلقائي على Render عند كل Commit.

## الملفات المتغيرة فقط

- `Dockerfile`
- `render.production.yaml`
- `scripts/render_build_verify.py` (جديد)

لم يتم حذف أو تعديل handlers أو services أو models أو migrations أو ميزات الطالب/المنصة/المالك.
