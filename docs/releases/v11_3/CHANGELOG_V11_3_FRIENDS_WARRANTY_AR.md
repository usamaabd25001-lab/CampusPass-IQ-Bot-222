# سجل تغييرات V11.3 — باقة أصدقائي فقط والضمان الآلي

## الإصدار

`11.3.0-friends-warranty`

## باقة أصدقائي فقط

- الميزة مغلقة افتراضياً لكل عرض، ولا تُفتح إلا بموافقة صاحب المنصة.
- دعم عدد ثابت أو عدد مخصص من 2 إلى 50 عضواً، مع قبول الأرقام العربية والإنجليزية.
- حجز عنصر مخزون واحد حصرياً للمجموعة لمدة 24 ساعة باستخدام قفل صف PostgreSQL.
- رابط دعوة Telegram Deep Link عشوائي؛ لا يُخزن الرمز الصريح، بل بصمة SHA-256 فقط.
- طلب مالي مستقل لكل عضو، مع رسوم بوت كاملة لكل عضو.
- تقسيم سعر الخدمة بالأعداد الصحيحة من دون فقدان أي دينار.
- Escrow Ledger منفصل للمجموعة مع مفاتيح Idempotency.
- اكتمال المجموعة لا يحدث إلا بعد دفع جميع الأعضاء.
- إنشاء مهام تسليم متزامنة لكل الأعضاء من حساب المخزون نفسه.
- بعد 24 ساعة من دون اكتمال العدد: إلغاء المجموعة، فك الحجز، وإعادة مبالغ الدافعين إلى محافظهم.
- إشعار كل عضو بحالة الاسترداد أو انتهاء المهلة.

## الضمان الآلي

- سياسة ضمان مستقلة لكل عرض تغطي مدة الاشتراك كاملة.
- المطالبة تظهر داخل «اشتراكاتي» فقط، ولا تظهر خارج مدة الضمان.
- تصنيف المشكلة: OTP، خروج/كلمة مرور، أو مشكلة أخرى، مع صورة إلزامية.
- وصول المطالبة إلى بريد المنصة الموحد بأولوية عاجلة.
- خيارات المعالجة: السماح بكود جديد، حساب بديل، أو رد نصي.
- لا يستطيع المزود إغلاق مطالبة الضمان من زر البريد العام.
- الحساب البديل لا يحل محل الحساب القديم في الاشتراك إلا بعد ضغط الطالب «جرّبت ونجح التفعيل».
- استمرار سحب OTP للطالب ذي الاشتراك والضمان الفعالين حتى لو امتلأ الحساب أو اختفى العرض من المتجر.
- قيد قاعدة بيانات PostgreSQL يمنع فتح مطالبتين نشطتين للاشتراك نفسه.
- حفظ جميع انتقالات المطالبة في سجل أحداث مستقل.

## الحماية والتزامن

- أقفال صفوف `FOR UPDATE` و`SKIP LOCKED` للحجز، الانضمام، الدفع، الاسترداد، والمخزون البديل.
- قيود Check Constraints للمبالغ وعدد الأعضاء وحالة Escrow.
- منع عدّ العضو المدفوع مرتين أثناء تأكيدات الدفع المتزامنة.
- معالجة انتهاء مجموعات الأصدقاء قبل مكنسة الحجوزات العامة.
- منع إرسال الحساب البديل مرتين عبر Delivery Outbox ومفتاح Idempotency.
- إبقاء مطالبة الضمان مفتوحة حتى تأكيد الطالب.

## تحديثات المكتبات

- Telegram Bot API target: `10.2`.
- aiogram: `3.30.0`.
- SQLAlchemy: `2.0.51`.
- Alembic: `1.18.5`.
- redis-py: `8.1.0` مع Retry/Exponential Backoff وبروتوكول RESP2 الصريح لتوافق Aiogram.
