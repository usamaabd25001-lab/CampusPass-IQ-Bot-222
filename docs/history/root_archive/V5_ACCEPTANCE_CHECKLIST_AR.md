# قائمة اختبار قبول v5 بعد النشر

ضع علامة بعد كل خطوة على نسخة Staging:

- [ ] `/start` يعرض لوحة Reply ولا تظهر شاشة فارغة.
- [ ] ضغط زر آخر أثناء انتظار كتابة مشكلة يلغي الانتظار ولا يحفظ اسم الزر كمشكلة.
- [ ] `/menu` و`/cancel` و`🏠 الرئيسية` تعمل من أي حالة.
- [ ] `/admin` يفتح للمالك المحدد في `ADMIN_IDS`.
- [ ] المالك يدخل منصة بدون إضافته كموظف.
- [ ] إنشاء قسم وخدمة وعرض يعمل مع رجوع وإلغاء.
- [ ] إدخال `10` يعطي تحذيرًا واقتراح `10000`.
- [ ] العرض لا ينشر بدون تعليمات تفعيل.
- [ ] النص والصورة/الملف في التعليمات تظهر للطالب.
- [ ] التسليم ينتظر إقرار قراءة التعليمات عندما يكون مطلوبًا.
- [ ] جلب رمز البريد ينجح على حساب تجريبي منفصل.
- [ ] المستخدم لا يرى أسرار IMAP.
- [ ] الطلب المكتمل يقبل تقييمًا من صاحبه فقط.
- [ ] متوسط المنصة وعدد التقييمات يظهران في الكتالوج.
- [ ] تقرير من كل نوع يفتح كـ A4 ويعرض شعار البوت والمنصة.
- [ ] Standard وPlus وPro تعرض مستويات مختلفة.
- [ ] الإعلان يصل مرة واحدة ويثبت ثم يفك بعد المدة.
- [ ] بلاغ مشكلة البوت يصل إلى المالك فقط.
- [ ] إخفاء زر وتحويله Reply/Inline لا يعطل أزرار الأمان.
- [ ] حذف عرض فيه طلب/مخزون/إيميل يؤدي إلى أرشفته لا حذف البيانات.
