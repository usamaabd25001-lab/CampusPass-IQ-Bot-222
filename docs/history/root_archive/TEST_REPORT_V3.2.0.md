# تقرير اختبار CampusPass IQ V3.2.0

## الفحوص المنفذة

- Ruff: ناجح.
- Python compileall: ناجح.
- Bandit security scan: ناجح دون نتائج عالية الخطورة.
- استيراد `app.main`: ناجح.
- فحص تطابق `VERSION.txt` مع إصدار التطبيق: ناجح.
- الاختبارات الآلية: 15 اختبارًا ناجحًا.

## سيناريوهات المستخدم

- قبول مجموعة متنوعة من الأسماء العراقية العربية.
- قبول أسماء مثل: اسامة، أسامة، أسماء، عبد الله، عبد الرحمن، ورؤى حسين طالب.
- تنظيف الحركات والتطويل والعلامات الخفية.
- رفض الأسماء الناقصة أو المحتوية على أرقام ورموز أو تكرار وهمي.
- فحص رقم الهاتف العراقي.
- فحص حساب السعر ورسوم الخدمة والعمولة.

## سيناريوهات الأزرار

- المستخدم العادي لا يرى لوحة الإدارة أو لوحة المنصة.
- مدير المنصة يرى لوحة المنصة دون لوحة الإدارة.
- المالك يرى لوحتي الإدارة والمنصة.
- تغيير زر واحد من كيبورد سفلي إلى زر داخل الرسالة.
- تشغيل الزر في المكانين معًا.
- إخفاء زر واحد دون التأثير على بقية الأزرار.
- تغيير اسم الزر مع بقاء الوظيفة نفسها.
- استمرار الاسم القديم في العمل للكيبوردات القديمة.
- منع تكرار اسمين متماثلين يسببان غموضًا.
- تغيير لون زر واحد.
- تغيير صف وترتيب زر واحد مع ثبات مكان زر آخر.
- تعطيل زر واحد والتحقق من اختفائه.
- توحيد جميع الأزرار ككيبورد أو كأزرار داخل الرسائل.
- فحص أطوال Callback Data وتوافقها مع حدود Telegram.
- فحص أن كل وظيفة مزروعة في القائمة مرتبطة بمعالج فعلي.

## اختبار التحديث والمحافظة على البيانات

تم إنشاء قاعدة بيانات على إصدار V3.1.1 وإضافة مستخدم قديم، ثم تشغيل V3.2.0 عليها. النتيجة:

- بقي المستخدم محفوظًا.
- أُنشئ سجل migration الجديد.
- لم تُحذف الجداول أو البيانات القديمة.
- تشغيل migrations مرتين لا يكرر التحديث.

## حدود الاختبار

لم تُنفذ عمليات حقيقية عبر Telegram أو Gmail أو Yahoo أو Mastercard؛ هذه تحتاج حسابات ومفاتيح خارجية حقيقية. تم اختبار الكود المحلي، قاعدة البيانات، الأزرار، المسارات والاستيراد دون اتصال خارجي.
