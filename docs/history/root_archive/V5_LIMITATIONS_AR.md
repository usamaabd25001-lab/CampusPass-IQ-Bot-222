# حدود v5.0.0 التي يجب معرفتها

## ما تم اختباره

- الاختبارات الآلية المحلية وقاعدة SQLite اختبارية.
- ترحيلات الجداول، التسعير، القوائم، التقارير، التقييمات والإعلانات الوهمية.
- محاكاة إرسال وتثبيت وفك تثبيت رسائل Telegram باستخدام FakeBot.

## ما يحتاج اختبارًا حيًا بعد النشر

- حساب Telegram حقيقي وصلاحية `ADMIN_IDS`.
- تثبيت الإعلان داخل المحادثة الخاصة الفعلية.
- رفع الصور والفيديو والملفات كتعليمات تفعيل.
- PostgreSQL وRedis على Railway.
- حسابات Gmail/Outlook/Yahoo حقيقية.
- أي بوابة دفع خارجية.

## البريد

البوت يختبر IMAP قبل حفظ الحساب. Gmail وYahoo قد يحتاجان App Password، وMicrosoft قد يرفض الدخول التقليدي حسب إعداد الحساب. OAuth2 الكامل غير مضمّن لأن تشغيله يحتاج Client ID وClient Secret وRedirect URI من حسابات المالك لدى مزود البريد.

## الدفع للميزات

أسعار الميزات والباقات والتقارير وإخفاؤها موجودة في قاعدة البيانات، والوصول مربوط بخطط وصلاحيات المنصة. الدفع الإلكتروني التلقائي لأي زر يحتاج بوابة دفع مفعلة ومفاتيح حقيقية؛ بدونها يستمر الدفع اليدوي وإثبات التحويل والموافقة.

## التقارير

الملفات الأساسية HTML A4 وCSV. PDF المباشر يحتاج محرك Chromium/Playwright أو خدمة PDF على السيرفر، ولم يُفرض داخل v5 حتى لا يفشل النشر بسبب حزم نظام كبيرة. يمكن فتح HTML وطباعته PDF من المتصفح.

## الإعلانات

البوت لا يستطيع إرسال إعلان إلى شخص لم يبدأ المحادثة معه أو قام بحظره. تثبيت الرسالة لا يمنع المستخدم من فكها من جهته.
