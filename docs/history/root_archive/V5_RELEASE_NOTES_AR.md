# CampusPass IQ v5.0.0 — التحديث الجذري

## الهدف
إعادة بناء تجربة الإدارة والشراء والتسليم حتى تكون واضحة لمالك البوت والمنصة والموظف والطالب، مع منع اختلاط حالات المحادثة وإتاحة التحكم من قاعدة البيانات بدل الأسعار والأزرار الثابتة داخل الكود.

## أهم الإضافات

### 1) التنقل ومنع اختلاط الحالات
- أوامر وقوائم رجوع ورئيسية وإلغاء عملية.
- عند اختيار قائمة جديدة تُنهى حالة الإدخال السابقة بأمان، فلا يُحفظ اسم الزر كمحتوى شكوى أو إجابة.
- إعادة إظهار لوحة القائمة بعد العمليات لتقليل حالات الشاشة الفارغة.
- معرفات الأزرار ثابتة، لذلك تغيير النص أو مكان العرض لا يغيّر الوظيفة.

### 2) منشئ قوائم حقيقي
- إنشاء زر نص أو صورة أو فيديو أو ملف أو رابط أو قائمة فرعية.
- تحديد من يرى الزر: طالب، منصة، أدمن، أو الجميع.
- وضع الزر في Reply Keyboard أو Inline Keyboard أو الاثنين.
- إخفاء أي زر بدون حذفه.
- تغيير اللون والترتيب والنص من لوحة المالك باستخدام أنماط Telegram الحالية.
- الإبقاء على الأسماء القديمة كمرادفات بعد إعادة تسمية الأزرار حتى تعمل لوحات الكيبورد القديمة.

### 3) صلاحية مالك البوت
- مالك البوت يُعامل كـ Super Admin عند وجود Telegram ID داخل ADMIN_IDS أو دور admin.
- يشاهد لوحة الإدارة ولوحة المنصة ولا يحتاج إلى إضافته كموظف في كل منصة.

### 4) أسعار تحت سيطرة المالك
- أسعار النظام والميزات والتقارير والباقات محفوظة في قاعدة البيانات.
- سجل كامل لكل تغيير: السعر السابق والجديد والمنفذ والسبب.
- المنصة تتحكم فقط بسعر خدماتها وعروضها.
- دعم الأرقام العربية والإنجليزية والفواصل.
- تحذير واضح عند كتابة 10 بدل 10000، وعرض السعر رقمًا وكتابةً قبل الحفظ.

### 5) طرق تسليم وتفعيل العروض
- إيميل + كلمة مرور.
- إيميل + رمز تحقق.
- إيميل + كلمة مرور + رمز تحقق.
- كود تفعيل فقط.
- بيانات مخصصة.
- تفعيل يدوي.

### 6) تعليمات تفعيل إجبارية
- لا يُنشر العرض بدون خطوة تعليمات واحدة على الأقل.
- تدعم نصوصًا وصورًا وفيديو وملفات وروابط.
- يمكن عرضها قبل التسليم وطلب إقرار الطالب بقراءتها.
- تبقى مرتبطة بالطلب ويمكن فتحها مرة أخرى.

### 7) البريد ورموز التفعيل
- اختبار اتصال البريد قبل اعتماده.
- دعم إعدادات IMAP لمزودي البريد، مع فصل بيانات المخزون عن بيانات قراءة الرموز.
- حجز البريد للطلب الصحيح ومنع إعادة استخدام الرسالة نفسها.
- عند عدم وضوح الرمز يُحوّل الطلب للدعم بدل إرسال رمز خاطئ.

### 8) تقييم المنصات والطلبات
- يظهر تقييم المنصة في قائمة المنصات والعرض والاشتراكات.
- عرض النجوم الذهبية الممتلئة والفارغة مثل ⭐⭐⭐☆☆.
- يظهر المتوسط وعدد الطلاب الذين قيّموا المنصة.
- التقييم متاح بعد اكتمال الطلب فقط ومن صاحب الطلب نفسه.
- تقييم واحد لكل طلب مع إمكانية تحديثه.

### 9) إعلانات مثبتة ومؤقتة
- إعلان نص أو صورة أو فيديو أو ملف مع زر رابط اختياري.
- استهداف الجميع أو الطلاب أو الأدمن أو المنصات أو جامعة/كلية/محافظة.
- تثبيت الإعلان في المحادثة الخاصة وفك التثبيت عند انتهاء المدة.
- سجل تسليم لكل مستخدم مع تسجيل الأخطاء بدون إيقاف الحملة.

### 10) بلاغ مشكلة في البوت
- بلاغ منفصل يصل لمالك البوت فقط.
- يحفظ رقمًا عامًا، التصنيف، الصفحة/الإجراء السابق، حالة المحادثة والمرفق الاختياري.
- حالات: مفتوح، قيد المعالجة، تم الحل.

### 11) تقارير A4
- قالب HTML مستقل بحجم A4.
- شعار CampusPass IQ أعلى اليمين ومكان شعار المنصة.
- تقارير يومية وأسبوعية وشهرية وفترة مخصصة.
- مستويات اعتيادي وPlus وPro.
- أنواع: عام، طلاب، مبيعات، كليات وتخصصات، محافظات، تقييمات، سحوبات.
- تنزيل HTML وCSV، وروابط تحقق آمنة.

### 12) تحديث إطار Telegram
- تحديث aiogram إلى 3.30.0 ودعم Bot API الحديث.
- استخدام ألوان الأزرار `primary` و`success` و`danger` عند دعم العميل لها.
- استخدام Reply Keyboard ثابتة وInline Keyboard حسب اختيار المالك.

## ملاحظات تشغيل
- يجب تشغيل ترحيلات قاعدة البيانات عند أول تشغيل للإصدار.
- لا تضع كلمات مرور البريد أو DATABASE_URL داخل GitHub.
- ربط Gmail وMicrosoft الاحترافي عبر OAuth2 ما يزال يحتاج بيانات تطبيق من حساب المالك؛ مسار IMAP موجود ويجب اختباره لكل بريد قبل الاعتماد.
