# دليل إدارة V4

## إنشاء متجر منصة

1. أضف المنصة والمالك من لوحة الإدارة.
2. امنح الموظف صلاحيات العروض والمخزون والدفع والدعم حسب دوره.
3. افتح لوحة المنصة ← `🛍 متجري والعروض`.
4. أضف قسمًا، مثل `🤖 أدوات الذكاء الاصطناعي`.
5. داخل القسم أضف خدمة، مثل `✨ Gemini`.
6. أضف العرض واختر السعر ورسوم البوت وطريقة التسليم والمدة.

## أنواع مدة العرض

- أيام من التفعيل: مثال 30 يومًا.
- أشهر تقويمية: 31 يناير + شهر = آخر يوم صالح من فبراير.
- تاريخ ثابت: جميع المشترِكين ينتهون في التاريخ نفسه.
- تاريخ المورد: كل حساب في المخزون يحمل نهايته الخاصة.
- يدوي: الموظف يحدد التاريخ عند التنفيذ؛ يستعمل للحالات الاستثنائية فقط.

اختر بداية الصلاحية بما يطابق الخدمة. الحساب الذي لا يبدأ إلا بعد الرمز يفضل `بعد تأكيد المستخدم نجاح التفعيل`.

## إضافة المخزون

- اختر عرض حساب أو كود.
- اكتب العنوان.
- أرسل البيانات؛ تُشفّر في قاعدة البيانات.
- للحساب استعمل JSON:

```json
{
  "login_email": "student@example.com",
  "login_password": "password",
  "instructions": "طريقة التفعيل"
}
```

لا تضع `imap_password` أو OAuth في نفس البيانات المرسلة للطالب. إعدادات صندوق البريد تُدار في وحدة الإيميلات.

## طرق الدفع

- تحويل إلى بطاقة: رقم البطاقة وتعليمات الصورة وآخر أربعة أرقام ورقم العملية.
- رصيد هاتف: رقم الهاتف والصورة أو معلومات العملية.
- تحويل يدوي: أي طريقة أخرى.

كل طريقة مرتبطة بالمنصة، ولا يستطيع طلب منصة استعمال طريقة منصة ثانية.

## معالجة طلب

```text
إثبات وصل
→ قيد التدقيق
→ قبول أو رفض
→ تثبيت الحجز
→ إنشاء مهمة التسليم
→ إرسال البيانات
→ تم التفعيل / لم يتم
→ مكتمل أو دعم
```

لا تضغط قبولًا إذا لم تطابق المبلغ والمرجع. لا ترسل بيانات الحساب يدويًا خارج الطلب، حتى يبقى الوصل والسجل صحيحين.

## اشتراكات الطالب

بعد التسليم يظهر الاشتراك في `📅 اشتراكاتي`. الوصل يحتفظ باسم المنصة والعرض والسعر والتواريخ وقت الشراء، حتى لو عدّل العرض لاحقًا.

## العمليات البطيئة

إذا تجاوزت العملية `PROCESSING_INDICATOR_DELAY_MS` يظهر نص المعالجة تلقائيًا، ثم يُحذف بعد النتيجة. عند خطأ غير متوقع يحصل المستخدم على رقم متابعة يمكن البحث عنه في Logs.

## صحة النظام

راجع دوريًا:

- قاعدة البيانات.
- مهام التسليم Pending/Failed.
- حسابات البريد التي تحتاج إعادة اتصال.
- إصدار التطبيق وMigration.
- حالة الوحدات الحرجة.
