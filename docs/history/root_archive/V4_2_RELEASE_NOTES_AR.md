# CampusPass IQ v4.2.0

## الجديد

- اعتماد الهوية البصرية لشعار CampusPass IQ داخل الملفات المصدّرة من البوت.
- إضافة مساحة ثابتة لشعار المنصة/المزوّد داخل كل تقرير، مع Placeholder واضح عند غياب الشعار.
- تنزيل التقرير بصيغة HTML أو CSV مباشرة من الرابط أو من أزرار البوت.
- إضافة إعدادات Brand مركزية: `EXPORT_LOGO_PATH`, `BRAND_PRIMARY_COLOR`, `BRAND_SECONDARY_COLOR`, `BRAND_DARK_COLOR`.
- تضمين شعار CampusPass IQ الأفقي داخل المشروع بشكل افتراضي.

## النتيجة

- جميع اختبارات المشروع: **33/33 ناجحة**.
- فحص Ruff: ناجح.
- فحص Compileall: ناجح.

## ملاحظة تشغيلية

لإظهار شعار المنصة داخل التقارير، يفضّل رفع **رابط شعار عام** للمزوّد داخل البوت. إذا لم يتوفر الشعار، سيظهر مكان مخصص محفوظ داخل الملف حتى يبقى التصميم متناسقًا.
