تاريخ الفحص: 2026-07-20

- Python 3.13.
- aiogram **3.30.0**.
- اختبارات قاعدة بيانات محلية ومعزولة.
- لا توجد أسرار إنتاج داخل الفحص.

- Pytest: **42 ناجح / 42**.

## ما تم التحقق منه

- بقاء Reply Keyboard مع `🏠 الرئيسية` و`❌ إلغاء العملية` حتى عند تحويل بقية الأزرار إلى Inline أو Hidden.
- إنشاء قوائم مخصصة متداخلة وحذفها بأمان.
- منع حذف القائمة الأم قبل حذف الأزرار التابعة لها.
- الأسعار تقبل الأرقام العربية والإنجليزية والفواصل.
- عرض `10000` كـ `10,000 د.ع` و«عشرة آلاف دينار».
- تأكيد وتحذير أسعار باقات المالك وأسعار عروض المنصات قبل الحفظ.
- تسجيل تغييرات الأسعار المهمة.
- تعليمات تفعيل متعددة الوسائط والتحقق من وجود خطوة مفيدة.
- انتظار إقرار التعليمات قبل التسليم عند تفعيل الشرط.
- تقييم الطلب المكتمل وتجميع التقييم في متوسط المنصة.
- عرض النجوم الممتلئة والفارغة وعدد المقيمين.
- منع التقييم من غير صاحب الطلب.
- إرسال الإعلان النشط مرة واحدة للمستخدم.
- استبدال الإعلان المثبت القديم بإعلان مثبت جديد.
- إنشاء تقرير HTML A4 مستقل مع شعار CampusPass IQ ومكان شعار المنصة.
- سبعة أنواع تقارير ومستويات Standard وPlus وPro.
- حماية حذف العروض: العرض المرتبط بطلب أو مخزون أو بريد يُؤرشف بدل حذف البيانات.
- تشغيل ترحيلات v5 وإضافة الجداول والقيم الافتراضية بدون حذف بيانات v4.

وهي: العام، الطلاب، المبيعات، الأكاديميات، المحافظات، التقييمات، والسحوبات.

## حدود الفحص

- لم يتم الدخول إلى البوت المنشور بحساب Telegram حقيقي.
- لم يتم تثبيت رسالة داخل محادثة حقيقية؛ تم اختبار المنطق بمحاكاة Bot API.
- لم تُستخدم قاعدة PostgreSQL الإنتاجية أو حسابات Gmail/Outlook/Yahoo حقيقية.
- OAuth2 للبريد يحتاج مفاتيح تطبيق من المالك، بينما مسار IMAP واختبار الاتصال موجودان.
- لم يتم تشغيل اختبار الضغط على قاعدة الإنتاج؛ ويجب ألا يحدث ذلك.
