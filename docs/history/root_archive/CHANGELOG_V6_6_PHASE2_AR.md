# سجل تغييرات V6.6 Phase 2

- إضافة جداول النزاعات وأحداثها والاسترجاعات ومعالجة المخزون.
- إضافة صلاحيات `can_manage_disputes` و`can_approve_refunds`.
- تجميد الطلب والاشتراك عند الاعتراض.
- قرارات رفض/تمديد/استرجاع كامل/جزئي.
- تأكيد تحويل الاسترجاع على مرحلتين.
- منع تكرار مرجع التحويل.
- عكس أرباح الإدارة والمنصة والنقاط بصورة idempotent.
- تحديث التقارير إلى إجمالي/استرجاعات/صافي.
- حماية المورد المكشوف من العودة للبيع.
- إضافة SLA وتصعيد للنزاعات المتأخرة.
- إكمال تلقائي بعد نافذة الاعتراض.
- إضافة واجهات Telegram للمستخدم والمنصة ومدير البوت.
- إضافة Migration واختبارات Phase 2.

## تشديد الاعتماد النهائي
- منع فتح شاشة النزاع من إرجاع حالات انتظار التحويل/المستخدم إلى قيد المراجعة.
- منع الرفض أو التمديد بعد بدء المسار المالي أو إنشاء سجل استرجاع.
- منع تغيير مبلغ استرجاع سبق اعتماده.
- تثبيت مرجع تحويل الاسترجاع بعد تسجيله ومنع استبداله دون مراجعة إدارية.
- تسجيل الموظف الذي أبلغ عن تحويل الاسترجاع.
- حصر تأكيد الاستلام بالمستخدم المستفيد أو مدير البوت.
- منع إكمال الاسترجاع إذا كانت بصمة التحويل أو وقت الإبلاغ ناقصين.
- عكس كامل نقاط الطلب والإحالة حتى إذا صُرفت سابقاً، مع السماح برصيد نقاط سالب يمثل ديناً ولائياً.
