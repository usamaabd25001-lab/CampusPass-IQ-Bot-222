# CampusPass IQ v5.0.5

- إدارة المستخدمين من لوحة المالك.
- حظر وفك حظر قابل للعكس.
- CSV كامل للمعلومات الإدارية دون كلمات مرور أو أسرار.
- حد افتراضي 3 مرات لتعديل معلومات الطالب، والمالك يغيره بأمر /editlimit.
- الحظر يوقف المستخدم قبل وصوله إلى عمليات البوت، مع استثناء مالك البوت.
- لا يوجد نظام آمن 100%؛ هذا التحديث يزيد الحماية ولا يغني عن النسخ الاحتياطي وتبديل الأسرار المكشوفة ومراجعة السجلات.
