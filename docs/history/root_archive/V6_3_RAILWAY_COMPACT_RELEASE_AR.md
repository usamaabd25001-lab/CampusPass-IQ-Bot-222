# CampusPass IQ V6.3 — Railway Compact Upload

هذا إصدار تغليف ونشر مخصص لرفع المشروع من واجهة GitHub على الهاتف.

- كود التطبيق الكامل محفوظ داخل `source_bundle.zip` في المستودع الخارجي.
- لا تحتاج إلى رفع مجلد `app` الذي يتجاوز 100 ملف.
- لا يعتمد النشر على مجلد `.github` المخفي.
- Railway يفك الحزمة أثناء البناء ثم يشغّل `python -m app.main`.
- قاعدة البيانات الخارجية تبقى المصدر الدائم للطلاب والمنصات والطلبات.

هذا التحديث لا يغيّر منطق الميزات الداخلية؛ هو تحديث نشر لتجاوز قيود رفع GitHub من المتصفح.
