# CampusPass IQ v5.0.4

إصلاحان مركزان:

1. منع توقف معالج إضافة العرض بعد تأكيد السعر. إذا تعذر جلب رسم النظام ديناميكيًا، يكمل البوت بالقيمة الاحتياطية الآمنة بدل التوقف.
2. تحسين تشخيص Gemini دون كشف المفتاح: يوضح في السجل هل FEATURE_GEMINI متوقف، أو المفتاح مفقود، أو API أعاد خطأ.

متغيرات Gemini المطلوبة في Railway:

- FEATURE_GEMINI=true
- GEMINI_API_KEY=<مفتاح Google AI Studio>
- GEMINI_MODEL=gemini-3.1-flash-lite

لا يحتوي الباتش على أي مفتاح سري ولا يغير قاعدة البيانات.
