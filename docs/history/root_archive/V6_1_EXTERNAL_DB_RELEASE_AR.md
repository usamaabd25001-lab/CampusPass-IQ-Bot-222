# CampusPass IQ V6.1 — External Database Edition

## المضاف في هذه الحزمة

- إلزام PostgreSQL خارجي في بيئة الإنتاج عند `REQUIRE_EXTERNAL_DATABASE=true`.
- رفض SQLite و`*.railway.internal` وRailway reference placeholders في هذا الوضع.
- دعم SSL مستقل عن صيغة الرابط: `require` أو `verify-full`.
- Connection pool محدود ومناسب للخطط الصغيرة.
- مهلة SQL، إعادة تدوير الاتصالات، وفحص `pool_pre_ping`.
- إعادة محاولة الاتصال عند بدء Railway بدلاً من فشل البوت بسبب تأخر القاعدة.
- تنظيف معاملات `sslmode` و`channel_binding` غير المتوافقة مع asyncpg.
- أداة نقل كاملة من PostgreSQL القديم إلى الخارجي.
- أداة فحص لا تطبع الأسرار.
- نسخة يومية مشفرة إلى Google Drive عبر GitHub Actions.
- أداة تحقق واستعادة للنسخ الاحتياطية.
- ملف Variables شامل لكل إعدادات التشغيل والميزات والنقل والنسخ.

## حدود هذه الحزمة

هذه الحزمة تعيد تهيئة طبقة الاستضافة والبيانات والنسخ الاحتياطي. الميزات التي كانت في V6 Foundation كخدمات داخلية ولم تكن مربوطة بكل واجهات Telegram لا تتحول تلقائياً إلى واجهات مكتملة بسبب تغيير قاعدة البيانات؛ ربطها الشامل يبقى عملاً منفصلاً عن فصل الاستضافة.
