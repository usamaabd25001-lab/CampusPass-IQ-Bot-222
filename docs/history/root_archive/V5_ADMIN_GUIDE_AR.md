# دليل مالك البوت والمنصة — CampusPass IQ v5.0.0

## دخول المالك

```text
/admin
```

المالك الحقيقي هو رقم Telegram الموجود في `ADMIN_IDS`. عند عدم التطابق يعرض البوت الرقم المطلوب إضافته بدل رسالة رفض غامضة.

## لوحة المالك

```text
👑 لوحة الإدارة
├── 🏢 المنصات
├── 🛍 الأقسام والخدمات والعروض
├── 🧱 منشئ القوائم والأزرار
├── 💰 الأسعار والميزات
├── 📊 التقارير وخططها
├── 📣 الإعلانات والتحديثات
├── 🐞 بلاغات مشاكل البوت
├── 👥 الموظفون والصلاحيات
├── 📧 الإيميلات والرموز
└── 🩺 صحة النظام
```

المالك يستطيع فتح لوحة أي منصة بصلاحيات كاملة ولا يحتاج إلى تسجيل نفسه كموظف فيها.

## إنشاء عرض بالطريقة الجديدة

```text
لوحة المنصة
→ 🛍 متجري والعروض
→ اختر/أضف قسمًا
→ اختر/أضف خدمة
→ ➕ إضافة عرض
```

التسلسل:

```text
اسم العرض
→ الوصف
→ السعر
→ مراجعة السعر رقمًا وكتابةً
→ طريقة التفعيل
→ الصلاحية
→ الحد اليومي
→ الشروط
→ تعليمات التفعيل الإجبارية
→ المعاينة
→ النشر
```

طرق التفعيل:

- إيميل + كلمة مرور.
- إيميل + رمز.
- إيميل + كلمة مرور + رمز.
- كود تفعيل.
- بيانات مخصصة.
- تفعيل يدوي.

## تعليمات التفعيل

لا ينشر العرض قبل إضافة خطوة واحدة على الأقل. الخطوة يمكن أن تكون:

```text
📝 نص
🖼 صورة
🎞 فيديو
📎 ملف
🔗 رابط
```

تظهر التعليمات للطالب قبل التسليم، ويمكن طلب إقراره بقراءتها، ثم ترسل مرة أخرى بعد بيانات الحساب. يبقى زر `📖 طريقة التفعيل` داخل الطلب.

## الأسعار

- المالك يتحكم بأسعار الباقات والتقارير والميزات ورسوم البوت.
- المنصة تتحكم فقط بسعر خدماتها وعروضها.
- كتابة `10` تعني عشرة دنانير، وليست عشرة آلاف.
- البوت يعرض `10,000 د.ع` و«عشرة آلاف دينار» قبل الحفظ.
- جميع تغييرات الأسعار المهمة تسجل مع المنفذ والقيمة القديمة والجديدة.

## الأزرار والقوائم

المالك يستطيع:

- إخفاء أي زر تجاري أو إداري قابل للإدارة.
- تحويله بين Reply Keyboard وInline Keyboard أو الاثنين.
- تغيير النص والترتيب واللون.
- إنشاء زر نص أو صورة أو فيديو أو ملف أو رابط أو قائمة فرعية.
- حذف زر مخصص عندما لا يحتوي أزرارًا فرعية.

أزرار الأمان التالية تبقى في Reply Keyboard لمنع الشاشة الفارغة:

```text
🏠 الرئيسية
❌ إلغاء العملية
```

## التقييمات

بعد اكتمال الطلب يظهر اختيار من نجمة إلى خمس نجوم. لا يستطيع شخص تقييم طلب مستخدم آخر، ويوجد تقييم واحد لكل طلب. يظهر للطلاب متوسط المنصة وعدد المقيمين، مثل:

```text
⭐⭐⭐⭐☆  4.2 من 5 — من 100 تقييم
```

## التقارير

من لوحة المنصة:

```text
📊 طلب تقرير
→ النوع
→ يومي / أسبوعي / شهري / مخصص
→ اعتيادي / Plus / Pro
→ إنشاء HTML A4
```

الأنواع:

- عام.
- الطلاب.
- المبيعات والمشتريات.
- الكليات والتخصصات.
- المحافظات.
- التقييمات ورضا الطلاب.
- السحوبات والمستحقات.

المالك يحدد مجانيتها أو سعرها وطريقة استحقاقها من الأسعار والميزات. التقرير المخصص يخضع لصلاحية الخطة، والمالك يتجاوز القيود.

## الإعلانات

```text
📣 الإعلانات والتحديثات
→ إنشاء إعلان
→ المستهدفون
→ المدة بالساعات
→ تثبيت أو إرسال عادي
→ معاينة ونشر
```

يمكن إرسال نص أو وسائط وزر رابط. الإعلان المثبت يفك تلقائيًا عند انتهاء المدة، والإعلان النشط يصل أيضًا للمستخدم الجديد عند فتح القائمة بدون تكرار.

## بلاغ مشكلة في البوت

داخل المساعدة يوجد `🐞 الإبلاغ عن مشكلة في البوت`. البلاغ يصل إلى المالك فقط، بينما مشكلة الطلب أو الخدمة تذهب إلى منصة الطلب. يمكن للمالك تحويل البلاغ إلى قيد المعالجة أو محلول.
