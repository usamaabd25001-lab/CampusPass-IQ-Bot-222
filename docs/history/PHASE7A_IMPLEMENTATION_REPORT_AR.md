# تقرير تنفيذ الفرع الأول V8.0-A

تم التنفيذ فوق V7.0 دون حذف أي بيانات.

## المكونات
- ثلاث باقات تجارية افتراضية.
- اشتراك تجاري واحد لكل مزود مع دورة وفترة سماح.
- فواتير متكررة Idempotent.
- دفتر قيود مزدوج يرفض أي قيد غير متوازن.
- مفاتيح API مخزنة كبصمة SHA-256 ولا يعاد عرض السر بعد الإنشاء.
- فرق مزودين وصلاحيات دقيقة.
- Webhooks مشفرة السر، HTTPS فقط، وطابور تسليم دائم مانع للتكرار.
- Dashboard مالي وإداري محمي.

## التوافق
كل الجداول والهجرة إضافية، ولم تتغير جداول الطلبات أو النزاعات أو المحافظ السابقة.
