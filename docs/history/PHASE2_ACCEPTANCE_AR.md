# معايير قبول Phase 2

- [x] المستخدم لا يفتح نزاعاً لطلب غير تابع له.
- [x] لا يفتح أكثر من نزاع رسمي لنفس الطلب.
- [x] النزاع يجمّد الطلب والاشتراك.
- [x] موظف بلا صلاحية لا يقرر نزاعاً أو استرجاعاً.
- [x] الرفض يعيد الحالة السابقة ويغلق التذكرة.
- [x] التمديد يعوض مدة التجميد ويضيف الأيام المعتمدة.
- [x] الاسترجاع لا يثبت قبل تسجيل التحويل وتأكيد الاستلام.
- [x] مرجع التحويل لا يستخدم في استرجاعين.
- [x] القيود المالية والنقاط لا تتكرر.
- [x] الاسترجاع الكامل يمنع المورد المكشوف من العودة للبيع.
- [x] التقارير تعرض صافي الربح بعد الاسترجاعات.
- [x] النزاع المتأخر يتصعد مرة واحدة.
- [x] الطلب المسلم يكتمل تلقائياً بعد انتهاء الاعتراض دون نزاع.
- [x] Migration وSchema وAST وCompile واختبارات الحماية ناجحة.
- [x] فتح شاشة النزاع لا يغيّر حالات الانتظار المالي.
- [x] لا يمكن رفض النزاع أو تحويله إلى تمديد بعد إنشاء استرجاع.
- [x] مرجع التحويل لا يمكن تبديله بعد إبلاغ المستخدم.
- [x] تأكيد الاستلام محصور بالمستفيد أو مدير البوت.
- [x] كامل النقاط المكتسبة تُعكس عند الاسترجاع الكامل حتى لو صُرفت.
